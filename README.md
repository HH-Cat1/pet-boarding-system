# 宠物寄养管理系统 · Pet Boarding Management System

> 数据库课程设计作品 · 纯前端可交互演示

一个完整的宠物寄养店业务管理系统演示，涵盖**客户 / 宠物 / 笼位 / 预约 / 寄养订单 / 服务记录 / 商品 / 员工 / 营收统计**等模块。

## 亮点
- **零后端、零安装**：整个系统打包成单个 HTML 文件，浏览器双击即开。
- **真实数据库**：前端用 `sql.js`（WebAssembly 版 SQLite）跑真实的 11 张表结构，下单、服务、结账、笼位释放等业务链全部可跑通。
- **数据可持久化**：数据存在浏览器本地（localStorage），刷新不丢；支持一键重置演示数据。
- **配套课程设计文档**：含 E-R 图（Chen 表示法）、数据流图、关系模式、MySQL DDL 等 7 章完整报告。

## 在线演示
部署到 GitHub Pages 后，把这里的网址贴进你的作品集即可，例如：

```
https://<你的GitHub用户名>.github.io/pet-boarding-system/
```

## 技术栈
- 前端：HTML + CSS + 原生 JavaScript
- 数据库：sql.js（SQLite 编译为 WebAssembly）
- 存储：浏览器 localStorage

## 功能一览
| 模块 | 说明 |
|------|------|
| 客户管理 | 增删改查寄养客户信息 |
| 宠物档案 | 宠物种类、年龄、备注 |
| 笼位管理 | 笼位状态（空闲/占用）、释放 |
| 预约 & 订单 | 创建寄养订单、关联笼位与宠物 |
| 服务记录 | 美容、洗澡等服务项登记与计费 |
| 商品 & 收银 | 商品销售、订单结账、押金管理 |
| 营收统计 | 订单数、营收、笼位利用率概览 |

## 本地运行
直接双击 `index.html` 即可；或在文件夹内起一个静态服务：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```
